# Agent System Prompts

Starter templates for all agent system prompts are in MASTER_KICKOFF_PROMPT.md
under the "AGENT PROMPT TEMPLATES" section.

Copy each one into its own file here before running the agent:
- dispatch-agent.md
- booking-agent.md
- invoice-agent.md
- operator-agent.md
- tech-assistant.md

These are plain .md files. The Edge Functions reference them by path.
Treat them as code — commit them, version them, and refine them as the agents improve.
